**Extract keyboard handler as a pure function** so it can be tested without React rendering:

```typescript
export interface ReviewKeyboardContext {
  activeItemId: string | null
  activeBatchId: string | null
  flatItems: Array<{ batchId: string; itemId: string }>
  onApprove: (batchId: string, itemId: string) => void
  onReject: (batchId: string, itemId: string) => void
  onNavigate: (batchId: string, itemId: string) => void
}

export function handleReviewKeydown(event: { key: string; target: { tagName: string; isContentEditable?: boolean }; preventDefault: () => void }, ctx: ReviewKeyboardContext): void
```

The function must:
1. Guard: return early if `target.tagName` is `'INPUT'`, `'TEXTAREA'`, `'SELECT'`, or `target.isContentEditable` is truthy.
2. If key is `'a'` or `'A'` and activeItemId/activeBatchId exist: call `event.preventDefault()`, call `ctx.onApprove(activeBatchId, activeItemId)`.
3. If key is `'r'` or `'R'` and activeItemId/activeBatchId exist: call `event.preventDefault()`, call `ctx.onReject(activeBatchId, activeItemId)`.
4. If key is `'ArrowDown'`: call `event.preventDefault()`, find current index in `flatItems`, advance to `Math.min(index + 1, flatItems.length - 1)`, call `ctx.onNavigate(next.batchId, next.itemId)`.
5. If key is `'ArrowUp'`: call `event.preventDefault()`, find current index, move to `Math.max(index - 1, 0)`, call `ctx.onNavigate(prev.batchId, prev.itemId)`.

**Implement tests first** — replace the `.todo` stubs in `review-keyboard.test.ts` with real implementations testing the pure function with mock callbacks.
