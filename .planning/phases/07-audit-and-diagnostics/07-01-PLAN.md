# Plan 01: Unified Audit Persistence & Crash Logging

## Objective
Establish the `audit_events` schema in the SQLite database and integrate `electron-log` for silent crash reporting.

## Overview
Phase 7 requires an event ledger and crash logs. This plan creates the unified persistence layer and sets up standard rolling file logs using `electron-log` bounded by our local-first constraints.
