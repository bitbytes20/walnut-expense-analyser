## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding in ledger rows |
| sm | 8px | Compact element spacing, badge margins |
| md | 16px | Default element spacing, row padding |
| lg | 24px | Section padding in Settings |
| xl | 32px | Layout gaps between summary cards and list |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (Audit workspace container) |

Exceptions: none

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 12px | 500 | 1.4 (Used for event metadata/timestamps) |
| Heading | 16px | 600 | 1.3 (Used for ledger dates / sections) |
| Display | 24px | 600 | 1.2 (Used for page titles) |

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg-primary)` | Background of the Audit workspace |
| Secondary (30%) | `var(--bg-secondary)` | Row hovers, filter panel, crash log cards |
| Accent (10%) | `var(--accent-blue)` | Active filter toggles, export buttons |
| Destructive | `var(--accent-red)` | Error badges, destructive delete keys |

Accent reserved for: Active filter state buttons (`[x] Security`), Primary Action ("Export Diagnostics Bundle").
